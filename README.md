# Rack Split

An offline planner for splitting a Facebook Marketplace Eurorack bundle between Parker and Andrea.

## Open it

Download or clone this repository, then open `index.html` in a browser. Nothing needs to be installed.

## Use it

- Drag a module from the common pool to Parker or Andrea, or back to the pool.
- Hover over a module to see what it does.
- Click a module to move it, read purchase checks or edit its estimated value.
- **Try suggested split** loads the recommended allocation.
- Function coverage shows each person's covered and missing synthesis functions.

Andrea's Cre8audio West Pest counts toward her capabilities but not the cash totals.

Each browser saves its own scenarios and price edits. Changes made in one browser do not sync to another.

## About the values

Dollar amounts are editable used-gear estimates for negotiating the split, not appraisals. Confirm each item's condition, and which enclosures and power adapters are included, before settling.
